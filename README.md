# FSD III Lab

Practice exercises and lab manual for the Full Stack Development III course, organized by week.

## Contents

The `FSD` folder contains the lab manual and weekly exercises (week1 through week10), covering front-end fundamentals with HTML, CSS, and JavaScript.

## Tech Stack

HTML, CSS, and JavaScript.

## Getting Started

Open the relevant week's folder and open its `index.html` file in a browser to view that exercise.
